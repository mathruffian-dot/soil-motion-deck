# 實作紀錄：〈畢氏定理〉（國中八年級）

這一次做出：簡報 13 頁，第 3、6、9 頁是動畫頁，片段 17.6／22.5／24.3 秒；影片 7 格、110 秒、−13.8 LUFS。簡報檔 2.3 MB（含三段片段），影片 8.9 MB。

## 規劃

1. **🎬 頁挑「變化就是重點」的頁。** 這次挑了數方格（9 + 16 = 25 一格一格填滿）、拼圖證明（四個三角形重新排列），以及三個迷思（翻牌：錯 → 打叉 → 翻成正確）。定義頁和表格頁用 SOIL 的版型就夠了，做成動畫反而比較慢。
2. **影片的分格跟著簡報走**，不要另外構思一支片。這次影片的 7 格分別對應簡報第 2、3、4–5、6、8、9、13 頁的內容，旁白一寫好，兩邊的用語就一致。
3. **梯子問題前後呼應**：第 1 格提出問題，第 5 格解答，兩格的梯子座標完全一樣：(601.25, 760) → (1000, 228.33)。共用的幾何要寫在 `_dispatch_context.md`，所有 worker 照抄。

## 剪片

4. **剪在轉場重疊的範圍外。** 相鄰兩格有 0.5 秒的交叉淡入淡出，兩格同時在畫面上。剪在那個範圍裡，片頭片尾會混到前後格的畫面。`cut_clips.py` 用每一格的 `data-start`／`data-duration` 算出和前後格重疊的範圍，從前一段重疊結束剪到下一段重疊開始，不管是哪一種轉場都適用，不必手算。兩格之間是直接切換的話，沒有重疊，就不用裁。
5. **片段一律重新編碼**：H.264、yuv420p、沒有音軌、`+faststart`，CRF 20。用 `-c copy` 只能在關鍵影格切，頭尾會多出半秒到兩秒。
6. **孿生版要整份複製再拿掉 audio 和字幕**，不要在原專案裡改 index.html 再改回來：輸出到一半如果出錯，原專案就壞了。

## PptxGenJS

7. **影片封面的格式**：`addMedia({ type: "video", path, cover })` 的 `cover` 照 PptxGenJS 的寫法，用 `"image/png;base64,<資料>"`，前面不加 `data:`。這次用這個格式，PowerPoint 的縮圖正確顯示封面。
8. **字型不會內嵌**：投影的電腦沒有源石黑體，就會退回系統字型。交付時要提醒使用者，或請他照 SOIL 的 F-0 安裝。
9. **用 PowerPoint 本身輸出縮圖**（COM，唯讀開啟、不顯示視窗）才看得到真正的影片封面和字型；LibreOffice 的縮圖可能換掉字型，只能拿來看版面。
14. **表格中文在 PowerPoint 編輯畫面變成方框**（後來的〈月相變化〉〈圓面積〉〈刻舟求劍〉三份都中）。比較頁的表格一打開就是一格格方框，數字照常顯示；同一頁的文字框正常，「另存成圖片」和 `thumbs.py` 的縮圖也正常，所以審查時完全沒發現。原因：PptxGenJS 把每個 run 的東亞字型寫成 `charset="-122"`（GB2312），表格格子的 `endParaRPr` 又寫成 `charset="0"`；源石黑體 TW 的 OS/2 字碼頁只宣告 Big5。實測：表格用微軟正黑體或不指定字型都正常；只把 charset 改成 Big5 沒用；拿掉 run 或 `endParaRPr` 任一邊的 charset 就正常。修法是存檔時拿掉所有字型標籤的 `charset`／`pitchFamily`（DrawingML 裡是選填）：`D.save()` 自動處理，其他情況用 `scripts/fix_cjk_fonts.py`，而且要放在所有改寫 XML 的步驟之後。

## 影片（同時寫進 motion-explainer 的 lessons.md）

10. `assemble-index` 要在字幕建好之後才跑，不然 index 裡沒有字幕軌，畫面上完全沒有字幕。
11. 數字的倒數或累加，要在旁白唸到那個數字之前就停下來（「等於十六」的時候，畫面上還是 17）。
12. 用 dash 描線的路徑不能用 `stroke-linecap: square`，不然線還沒畫出來就先露出一個小點。
13. 翻牌卡的正反兩面疊在一起：在兩面的容器上加 `data-layout-allow-overlap`。
